Technical Skills

57 technical paths. Mas matagal mag-build (6-18 buwan). Pero mas mataas ang rate, ₱100K-₱500K+/month.

Length: 15 minutes (to pick) For: Anyone considering the developer / data / IT path Updated: 2026-05-15 (v2)

"Ate, friend ko nag-Coding bootcamp. Nakuha ng $5,000/month na job. Kaya ko ba 'yan?"

Ronan, SWAHG group, ambitious member

Kaya, friend. Pero matagal-tagal. 6-18 buwan ng focused practice bago first paying gig. Hindi 30-day path. Pero ang ceiling, $5K-$15K/month for senior developer in PH. Higher than any other lane sa SWAHG. Today natin titignan kung fit sa archetype mo.

The wrong question vs the right question

Mali: "Mahirap ba mag-code?"

Tama: "Kaya ko bang mag-commit ng 10-20 hrs/week sa loob ng 12-18 buwan bago first dev paycheck?"

Free entry points

Bago ka magbayad LinkedIn Learning, try freeCodeCamp (free 1000-hour curriculum) or The Odin Project (free full-stack). Pag nag-stick ka after 30 days, doon mag-LinkedIn Learning.

The honest moment

I'm not a developer myself. Pero may daily Claude Code work ako, basic HTML/CSS knowledge sa writingsbylala.com rebuild. Yung "technical literacy" ay possible. Yung "full-stack engineer" ay different commitment. Honest about which one you're targeting.

Yung warning sa "30-day coding bootcamp na ₱5K/month gig"

Realistic timelines

YouTube ads sell "code in 30 days = $5K/month." That's not how it works. Junior WordPress developer realistic timeline: 6-12 months of consistent practice. Front-end developer: 12-18 months. Yung sumusuko sa month 3, hindi natin sila masisi pero hindi din professional. Yung sumusunod sa 18-month plan, yan ang humihingit.

Practice. Decide if this lane fits. 12 minutes.

  1. Honest answer: can I commit 10-20 hrs/week for 12-18 months? Yes = continue.
  2. Try free 30-day trial sa freeCodeCamp. Pag-enjoy at na-stick ka, this is your lane.
  3. Pag pumasa, pick one of the 6 paths above. Add to Calendar.
  4. If you didn't stick after 30 days, return to Lessons 17-18. Hindi yan failure. Yan ay self-knowledge.

Action items, depende sa archetype mo

🌟 The Polished Freelancer~25%

Tech path is career pivot, hindi side-skill.

Do this week
  1. Decide if pivoting careers or adding adjacent skill.
  2. If pivoting: UX Designer (12 mo) or Data Analytics (6-9 mo).
  3. If adjacent: Advanced Excel (3 mo). Multiplies current rate.
💼 The Corporate Transitioner~30%

Tech-savvy from corp world. Realistic path.

Do this week
  1. Junior WordPress or QA Engineer. Reachable in 9-12 months.
  2. Use existing employer's training budget if available.
  3. Apply to "Junior" labeled remote roles only. Hindi pa "Senior."
🎨 The Creative Specialist~15%

UX Designer is the natural creative-to-tech bridge.

Do this week
  1. UX Designer path. Visual design + research = your strength.
  2. Add Figma mastery alongside.
  3. Apply to SaaS startup UX roles after 12 months. Premium tier.
🛒 The Solo Entrepreneur~15%

WordPress / Shopify dev = revenue-tied. High leverage.

Do this week
  1. Junior WordPress / Shopify developer. Yung shop experience mo = client empathy.
  2. Build first 3 mock client sites in WP / Shopify. Real portfolio.
📋 The Generalist Admin~10%

Data Analytics is best fit (Excel-fluent already).

Do this week
  1. Advanced Excel + SQL → Data Analyst. Builds on existing.
  2. Free Google Data Analytics Certificate on Coursera. 3-6 months part-time.
🌱 The Fresh Starter~5%

Tech is high-ceiling but unrealistic for first 12 months.

Do this week
  1. Skip this lesson for now. Return after first VA client.
  2. If exploring: free freeCodeCamp 1 hr/day. No commitment.
