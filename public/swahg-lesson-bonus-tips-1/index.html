Organize Your Work Files

Yung 3-rule trifecta: files, browser, tools. Yung deeper version ng Lessons 03 + 04.

Length: 30 minutes For: Anyone past first client + ready for systems Updated: 2026-05-15 (v2)

"May system na akong files. Pero pag-overload, nakakawalang gana mag-organize."

Common question from new SWAHG learners

Friend, hindi sa motivation yung problem. Walang automation. Yung 3-rule bonus tip natin = files + browser + tools. Pag pareho silang isang system, hindi mo na kailangan ng motivation. Automatic na.

The 3-rule organization trifecta

RuleWhat to doTool / setting
1. Files not scattered + backed upCloud-first. Auto-backup Downloads. Per-client folder.Google Drive + Backup and Sync
2. Organized browser + bookmarksPer-profile work browser. Bookmarks bar with categories.Chrome multi-profile (per Lesson 03)
3. Tools organized via Google AppsOne Google ecosystem (Drive, Docs, Sheets, Calendar, Tasks).Google Workspace or free Gmail

Yung tool ecosystem ko

Single ecosystem = less context-switching

Documents
Google Docs primary. Notion for personal long-form.
Spreadsheets
Google Sheets for client trackers + analytics.
Calendar + Tasks
Google Calendar for client schedules + recurring rituals.
Communication
Gmail primary. Slack only when client requires.

Yung warning sa tool-hopping

Stick to ONE ecosystem

Pag pareho mo Google Workspace + Notion + ClickUp + Asana + Apple Notes + Bear + Things, yung file mo nasaan? Pick one primary ecosystem. Add tools only when ecosystem gap is real.

Practice. Audit + consolidate. 30 min.

  1. List every tool you currently use. Tools, apps, sites.
  2. Identify duplicates. Yung 2 todo apps? 3 note-takers? Eliminate.
  3. Pick PRIMARY ecosystem. Google or Apple or Microsoft.
  4. Migrate all data to primary. Then archive secondaries.
  5. Setup Friday 15-min cleanup ritual. Calendar recurring.

Action items, depende sa archetype mo

Do this week

  2. External SSD for active project files.
🛒 Solo

Migrating from shop tools. Clean break.

Do this week
  1. Export Shopify + Mailchimp data.
  2. Setup separate Drive for VA work.
📋 Generalist

Most naturally organized. Document for others.

Do this week
  1. Build SOP doc for file organization.
  2. Sell as service (₱5K setup fee).

Start clean. Don't over-engineer.

Do this week
  1. Free Google Drive + 5 root folders.
  2. Add tools only as client requires.
