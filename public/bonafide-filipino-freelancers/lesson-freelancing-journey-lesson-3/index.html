Create a Resume That Stands Out

The 1-2 page document that makes your first impression. Not 5 pages, not 1 line.

Length: 60-90 minutes (resume build) For: Active Freelancing Journey learners Updated: 2026-05-15 (v2)

"I do not know how to make a resume that does not look BPO-style."

Common Freelancing Journey Lesson 3 question

Friend, you have two options. (1) The old path: build it in Word with manual layout. (2) The modern path: use the interactive BFF Resume Builder. The second option is faster, archetype-aware, and includes live job-match. Both are available. Your choice.

The 5-step assignment (Canva path)

#Step
1Watch the lesson video.
2Create account at canva.com. Free.
3Search "Resume" templates. Pick ATS-friendly one (single-column, no graphics-heavy).
4Fill in: contact, professional summary (from Lesson 14), skills, experience, education.
5Get shareable link. Submit via ASSIGNMENT TRACKER FORM (Title: Lesson 3).
Alternative: BFF Resume Builder

The BFF Resume Builder is already built. Step-by-step. Start with a desired job, existing resume, or archetype. Auto-fill skills. Create an editable starter draft. Letterpress preview. Export PDF. It is not wrong to use this instead of Canva. The output goal is the same.

The non-negotiable resume sections

1-page structure

Header
Name + role title + city + email + LinkedIn + portfolio link
Professional Summary
2-3 sentences. Wedge-specific. No clichés.
Skills (4-8)
Work-used, not aspirational. From the Resume Builder tool rating.
Experience
Reverse chronological. Bulleted achievements with numbers.
Education
School + degree + year (only if recent or relevant).
Certifications
Any cert from Lesson 17-19 work. Even partial.

The warning about "design over content"

ATS-friendly

Canva templates sometimes have multi-column layouts + graphics. The client's ATS (Applicant Tracking System) may not be able to parse those. Single column. Standard fonts. No icons in skill names. Tasteful design is enough.

Practice. Build first resume. 90 min.

  1. Decide: Canva or BFF Resume Builder.
  2. If Canva: pick ATS-friendly template. Single column.
  3. If BFF Resume Builder: open it. 7-step wizard.
  4. Fill in all sections honestly. No padding.
  5. Export PDF. Test shareable link in incognito browser.
  6. Submit via ASSIGNMENT TRACKER FORM.
