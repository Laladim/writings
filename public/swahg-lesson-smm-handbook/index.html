The warning about "I'll read it later"

Download = read = apply

Many SWAHG learners only download resources and never read them. The Handbook is action-oriented. Every section has an exercise. If there is no exercise output, no learning happened.

Practice. Get + apply 3 sections. 60 minutes total.

  1. DM Work At Home Geek page for password.
  2. Download the SMM Handbook.
  3. Open Section 4 (6-Step Process of Creating Content). Apply to ONE post.
  4. Open Section 7 (10 Ways of Finding Your Client). Pick 3 ways. Try them this week.
  5. Open Section 16 (Branding Templates). Apply ONE template to your own brand.
