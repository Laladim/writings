YouTube Best Practices

Long-form + Shorts = dual strategy. Build authority + reach simultaneously.

Length: 22 minutes For: SMM specialists supporting course creators, B2B brands, podcasters Updated: 2026-05-15 (v2)

"Sabi ng client gusto niya mag-YouTube. Pero hindi ako videographer."

Common question from new SWAHG learners

Friend, hindi mo kailangan to be a videographer. Yung SMM YouTube role ay: strategy, thumbnails, titles, descriptions, scheduling, analytics, community management. Yung video shooting + editing, separate hire (or you upskill). Today natin sasamahan ang core SMM-for-YouTube workflow.

The wrong question vs the right question

Mali: "Anong viral title ngayon?"

Tama: "Anong content pillars + posting cadence ang magbi-build ng audience over 12-24 months?"

Yung warning sa Shorts-only strategy

Shorts ay reach. Long-form ay revenue.

Shorts get views but ad rev is low. Long-form drives subscription, course sales, sponsorship. Balanced strategy: Shorts for reach, long-form for monetization.

Practice. Build YT strategy doc. 30 min.

  1. Pick a client (or test channel).
  2. Define 3 content pillars. What's the channel about?
  3. Set cadence: 1 long-form/week + 3 Shorts/week. Sustainable.
  4. Build first 4 video titles + thumbnails in Canva.
  5. Schedule via YouTube Studio.
